# Cinematic Liquid Glass & Creative Studio Experience

A dark cinematic landing web application built with **React 18**, **TypeScript**, **Tailwind CSS 3**, and **Framer Motion**, showcasing liquid glass morphism UI elements, custom requestAnimationFrame fading background video loops, word-by-word blur animations, and progressive scroll-linked typography.

---

## 🌟 Visual Specifications & Features

### 1. Asme Cinematic Hero
- **Full-Screen Looping Video**: Positioned with 17% downward crop (`translate-y-[17%]`) ensuring atmospheric focus on the action.
- **Custom RAF Video Fade Engine**: 500ms requestAnimationFrame fade-in on start, 500-550ms fade-out before video concludes, seamless replay without CSS transition artifacts.
- **Liquid Glass Navigation Bar**: Borderless frosted glass with dual-pass linear-gradient stroke borders via `-webkit-mask` composite exclusion.
- **Interactive Email Dispatch**: Transparent input with circular arrow button and direct subscription feedback.
- **Instrument Serif Typography**: Elegant editorial serif headline *"Built for the curious"*.

### 2. Agency Hero & Capabilities
- **Headline BlurText**: Word-by-word staggered blur-in Framer Motion animation (*"Crafted Digital Experiences Built to Outlast Trends"*).
- **Interactive Metrics Cards**: Liquid glass stat badges (*"6 Weeks"*, *"140+ Brands"*).
- **Brand Trust Bar**: Worldwide creative director recognition (*Aeon, Vela, Apex, Orbit, Zeno*).
- **Capabilities Section**: Atmospheric video background with 3 glass cards (**Design**, **Engineering**, **Growth**) featuring custom iconography and tags.

### 3. Prisma Creative Studio
- **Inset Video Frame**: Bordered rounded viewport with `.noise-overlay` turbulence filter and gradient contrast.
- **Hanging Navigation Pill**: Black background pill hanging from top edge.
- **Giant Hero Wordmark**: Fluid responsive typography (*"Prisma\*"*) with pull-up animation.
- **Marcus Chen About Narrative**: Multi-style animated text with scroll-linked character-by-character opacity progressive reveal.
- **4-Column Feature Cards**: Video canvas preview, Storyboard (01), Smart Critiques (02), and Immersion Capsule (03).

### 4. Interactive Components
- **4K Showreel Modal**: High-definition video player with play/pause, spatial sound toggle, and fullscreen capabilities.
- **Project Inquiries & Manifesto Modal**: Collaborative brief submission and studio manifesto.
- **Experience Controller**: Floating bottom pill allowing switching between full journey and individual viewports.

## 📦 Installation & Local Development

```powershell

```

2. Install dependencies:
```powershell

```

3. Start development server:
